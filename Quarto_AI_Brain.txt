# The Stillness of Growth {.mb-5}


자산의 성장만큼이나 일상의 수율을 높이는 정교한 시스템에 집중합니다. 지속 가능한 투자를 설계하고, 찰나의 빛을 기록하며, 매일의 러닝과 코딩으로 삶의 밀도를 채워갑니다. 공학자의 시선으로 세상을 관측하며 얻은 이 기록들이, 각자의 목표를 향해 달리는 당신의 여정에도 든든한 전략적 페이스메이커가 되기를 바랍니다.

```{=html}
<div class="chart-container-wrapper" style="display: block; width: 100%; clear: both; margin: 3rem 0; padding: 1rem 0;">
  <div id="assetChart" style="width: 100%; max-width: 850px; height: 550px; margin: 0 auto; position: relative;">
    <p id="statusMsg" style="text-align: center; color: #86868b; padding-top: 220px; font-family: 'SF Pro Text', sans-serif;">
      데이터를 불러오는 중입니다...
    </p>
  </div>
</div>

<div style="clear: both;"></div> <script>
  (function() {
    const sheetID = "1ZgcJc8n-pC4crM3zqq4LPUJ9hTGbmhgpfV6XI87wr5A";
    const gid = "0"; 
    const finalUrl = `https://docs.google.com/spreadsheets/d/${sheetID}/gviz/tq?tqx=out:csv&gid=${gid}`;

    function startApp() {
      const container = document.getElementById('assetChart');
      if (typeof Plotly === 'undefined') { setTimeout(startApp, 200); return; }

      fetch(finalUrl)
        .then(res => res.text())
        .then(csvText => {
          container.innerHTML = "";
          
          const rows = csvText.split(/\r?\n/).filter(line => line.trim() !== "");
          const labels = [];
          const values = [];

          for (let i = 1; i < rows.length; i++) {
            const cols = rows[i].split(/,(?=(?:(?:[^"]*"){2})*[^"]*$)/);
            // [데이터 무결성 복구] I열(Index 8)의 Portfolio Weight를 정확히 조준합니다.
            if (cols.length >= 9) {
              const ticker = cols[0].replace(/"/g, '').trim();
              const weightStr = cols[8].replace(/"/g, '').replace('%', '').trim();
              const weight = parseFloat(weightStr);
              
              if (!isNaN(weight) && weight > 0) {
                labels.push(ticker);
                values.push(weight);
              }
            }
          }

          // Plotly 도넛 차트 렌더링
          Plotly.newPlot('assetChart', [{
```

```{=html}
            .then(res => res.text())

              const labels = []; const values = [];
              for (let i = 1; i < rows.length; i++) {

                  const ticker = cols[0].replace(/"/g, '').trim();

                }
              }
              drawMatrix02(container02, labels, values);
            });
        } else {
```

```{=html}
<div class="lightbox-thumb-rail" id="lightboxThumbRail"></div>
</div>
</div>

<script>
document.addEventListener("DOMContentLoaded", function() {
  const gridZone = document.getElementById('galleryGrid');
  const sidebarZone = document.getElementById('gallerySidebar');
  
  const modal = document.getElementById('lightboxModal');
  const closeBtn = document.getElementById('lightboxClose');
  const targetImg = document.getElementById('lightboxTargetImg');
  const targetTitle = document.getElementById('lightboxTargetTitle');
  const targetDate = document.getElementById('lightboxTargetDate');
  const targetDesc = document.getElementById('lightboxTargetDesc');
  const targetTags = document.getElementById('lightboxTargetTags');
  const thumbRail = document.getElementById('lightboxThumbRail');
  
  const activeFilters = { period: 'all', theme: 'all', camera: 'all' };
  let globalPhotoData = [];
  let currentRenderedData = [];
  let activeIndex = 0;

  fetch('gallery.json')
    .then(res => {
      if(!res.ok) throw new Error("데이터 파이프라인 결합 에러");
      return res.json();
    })
    .then(data => {
      globalPhotoData = data;
      buildEngine();
    })
    .catch(err => {
      gridZone.innerHTML = `<p style="color: #ff3b30; text-align: center;">자산 인입 오염: ${err.message}</p>`;
    });

  function buildEngine() {
    const periods = new Set();
    const themes = new Set();
    const cameras = new Set();

    globalPhotoData.forEach(item => {
      const yearStr = item.period ? item.period.substring(0, 4) : "Unknown";
      const yearVal = parseInt(yearStr);
      let decadeStr = "Unknown";
      
      if (!isNaN(yearVal)) {
        const decadeVal = Math.floor(yearVal / 10) * 10;
        decadeStr = decadeVal + "s";
        periods.add(decadeStr);
      } else {
        periods.add("Unknown");
      }

      const themeTheme = item.theme || "Unknown";
      const cameraCamera = item.camera || "Unknown";

      themes.add(themeTheme);
      cameras.add(cameraCamera);

      item.computed = { period: decadeStr, theme: themeTheme, camera: cameraCamera, rawPeriod: item.period || "Unknown" };
    });

    renderFilterBlock('Period', periods, 'period');
    renderFilterBlock('Theme', themes, 'theme');
    renderFilterBlock('Camera', cameras, 'camera');

    executeCrossFilter();
  }

  function renderFilterBlock(title, dataSet, filterKey) {
    const sorted = Array.from(dataSet).sort();
    if(filterKey === 'period') {
      sorted.sort((a, b) => b.localeCompare(a));
    }

    const rowBlock = document.createElement('div');
    rowBlock.className = 'gallery-filter-row';
    
    let html = `<div class="gallery-filter-title">${title}</div>`;
    html += `<div class="gallery-filter-chips-group">`;
    html += `<a href="#" class="gallery-filter-link active" data-key="${filterKey}" data-val="all">All</a>`;
    sorted.forEach(val => {
      html += `<a href="#" class="gallery-filter-link" data-key="${filterKey}" data-val="${val}">${val}</a>`;
    });
    html += `</div>`;
    
    rowBlock.innerHTML = html;
    sidebarZone.appendChild(rowBlock);

    rowBlock.querySelectorAll('.gallery-filter-link').forEach(link => {
      link.addEventListener('click', function(e) {
        e.preventDefault();
        rowBlock.querySelectorAll('.gallery-filter-link').forEach(l => l.classList.remove('active'));
        this.classList.add('active');

        activeFilters[filterKey] = this.getAttribute('data-val');
        executeCrossFilter();
      });
    });
  }

  function executeCrossFilter() {
    gridZone.innerHTML = '';
    
    currentRenderedData = globalPhotoData.filter(item => {
      const matchPeriod = (activeFilters.period === 'all') || (item.computed.period === activeFilters.period);
      const matchTheme = (activeFilters.theme === 'all') || (item.computed.theme === activeFilters.theme);
      const matchCamera = (activeFilters.camera === 'all') || (item.computed.camera === activeFilters.camera);
      return matchPeriod && matchTheme && matchCamera;
    });

    if(currentRenderedData.length === 0) {
      gridZone.innerHTML = `<p style="grid-column: span 3; color: #86868b; text-align: center; padding: 4rem 0;">조건에 매칭되는 사진 자산이 없습니다.</p>`;
      return;
    }

    currentRenderedData.forEach((item, index) => {
      const card = document.createElement('div');
      card.className = 'gallery-photo-card';
      
      card.innerHTML = `
        <img src="${item.image}" class="gallery-card-img" alt="${item.title}" loading="lazy">
        <div class="gallery-hover-overlay">
          <div class="gallery-hover-title">${item.title}</div>
        </div>
      `;
      
      card.addEventListener('click', () => {
        openLightbox(index);
      });

      gridZone.appendChild(card);
    });
  }

  function openLightbox(index) {
    activeIndex = index;
    modal.style.display = 'flex';
    document.body.style.overflow = 'hidden';
    
    updateLightboxStage();
    buildThumbnailRail();
  }

  function updateLightboxStage() {
    const activeData = currentRenderedData[activeIndex];
    
    targetImg.src = activeData.image;
    targetTitle.innerText = activeData.title;
    targetDate.innerText = activeData.computed.rawPeriod;
    targetDesc.innerText = activeData.desc || '';
    
    targetTags.innerHTML = '';
    const chips = [activeData.computed.rawPeriod, activeData.computed.theme, activeData.computed.camera].filter(Boolean);
    chips.forEach(chip => {
      const span = document.createElement('span');
      span.className = 'lightbox-tag-chip';
      span.innerText = chip;
      targetTags.appendChild(span);
    });

    const thumbNodes = thumbRail.querySelectorAll('.rail-thumb-node');
    thumbNodes.forEach((node, idx) => {
      if(idx === activeIndex) {
        node.classList.add('active');
        node.scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'center' });
      } else {
        node.classList.remove('active');
      }
    });
  }

  function buildThumbnailRail() {
    thumbRail.innerHTML = '';
    
    currentRenderedData.forEach((item, idx) => {
      const imgNode = document.createElement('img');
      imgNode.src = item.image;
      imgNode.className = 'rail-thumb-node';
      if(idx === activeIndex) imgNode.classList.add('active');
      
      imgNode.addEventListener('click', () => {
        activeIndex = idx;
        updateLightboxStage();
      });
      
      thumbRail.appendChild(imgNode);
    });
  }

  closeBtn.addEventListener('click', () => {
    modal.style.display = 'none';
    document.body.style.overflow = '';
  });

  modal.addEventListener('click', (e) => {
    if(e.target === modal) {
      modal.style.display = 'none';
      document.body.style.overflow = '';
    }
  });

  document.addEventListener('keydown', (e) => {
    if (modal.style.display === 'flex') {
      if (e.key === 'Escape') {
        modal.style.display = 'none';
        document.body.style.overflow = '';
      } else if (e.key === 'ArrowRight') {
        if (activeIndex < currentRenderedData.length - 1) {
          activeIndex++;
          updateLightboxStage();
        }
      } else if (e.key === 'ArrowLeft') {
        if (activeIndex > 0) {
          activeIndex--;
          updateLightboxStage();
        }
      }
    }
  });
});
</script>
```
